# NBA + G League → Telegram

Бот каждые 60 секунд проверяет новостные источники и сразу публикует новое в ваш Telegram-канал.

## Источники

| Источник | Тип | Что даёт |
|---|---|---|
| NBA.com/news | официальный | новости лиги, травмы, обмены |
| pr.nba.com (NBA Communications) | официальный, пресс-служба | официальные заявления лиги (WNBA и BAL отфильтрованы) |
| gleague.nba.com/news | официальный | подписания two-way, обмены и права G League |
| ESPN NBA | СМИ | самые быстрые инсайды |
| CBS Sports NBA | СМИ | новости и аналитика (MLB/NFL отфильтрованы) |
| Yahoo Sports NBA | СМИ | выключен по умолчанию — много фан-блогов |

Список правится в `sources.yaml`. Если одна и та же новость пришла из двух источников, второй раз она не публикуется (сравнение заголовков).

## Шаг 1. Канал и бот в Telegram

1. Создайте канал в Telegram (публичный, например `@nba_gleague_news`).
2. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
3. Добавьте бота в канал **администратором** с правом «Публикация сообщений».

## Шаг 2. Настройка

```bash
cp .env.example .env
```
Впишите в `.env` токен и `@имя_канала`. По умолчанию заголовки переводятся на русский, а оригинал показывается ниже курсивом.

## Запуск на GitHub Actions (основной способ)

Бот работает сменами по ~5,5 часа и сам запускает следующую смену, источники опрашиваются раз в минуту.
Состояние (какие новости уже опубликованы, список травм) хранится в кэше Actions.

Что публикуется:
- 🚑 **травмы** — сразу при появлении в официальном списке травм, смене статуса или возвращении игрока (карточка с фото);
- 🏁 **итоги матчей** — карточка со счётом по четвертям, командной статистикой и лучшими игроками;
- 🔁 ✍️ 😤 👀 **новости** — обмены, контракты, конфликты, слухи, официальные заявления, с рубрикой и картинкой;
- фэнтези, ставки и WNBA отсеиваются.

Секреты (Settings → Secrets and variables → Actions):

| Секрет | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID` | обязательно |
| `GEMINI_API_KEY` | **качественный перевод** нейросетью (бесплатный ключ: aistudio.google.com → Get API key) |
| `OPENAI_API_KEY` (+ `OPENAI_BASE_URL`, `OPENAI_MODEL`) | альтернатива Gemini: любой OpenAI-совместимый сервис |
| `DEEPL_API_KEY`, `MYMEMORY_EMAIL` | запасной машинный перевод |

Личная статистика подписчиков: в личном чате с ботом подписчик пишет имя игрока — бот добавляет его в список
(до 12). Кнопка «📊 Статистика» показывает по каждому: статус (травма / в строю), последний и следующий матч,
итоги сезона — PTS, FG%, FT%, 3PM, REB, AST, STL, BLK, TOV (всего и за игру). Списки хранятся в `data/` (кэш Actions).
В канале закреплён пост с кнопкой, ведущей в чат с ботом; такая же кнопка есть под итогами матчей.

Служебные команды — Actions → NBA news to Telegram → Run workflow, поле `mode`:
`run` — обычная работа, `demo` — по примеру каждого типа поста, `test` — тестовое сообщение, `check` — проверка источников,
`report` — что и сколько опубликовано, `button` — пост с кнопкой статистики в канал, `usertest` — проверка личной статистики.

## Шаг 3. Запуск на своём сервере

Боту нужно работать постоянно, поэтому лучше всего — недорогой VPS (любой Linux-сервер).

**Вариант A — Docker:**
```bash
docker build -t nba-bot .
docker run -d --name nba-bot --restart=always --env-file .env -v $(pwd)/data:/app/data nba-bot
docker logs -f nba-bot
```

**Вариант B — Python + systemd:**
```bash
sudo mkdir -p /opt/nba-news-bot && sudo cp -r . /opt/nba-news-bot && cd /opt/nba-news-bot
sudo useradd -r nbabot; sudo chown -R nbabot /opt/nba-news-bot
sudo -u nbabot python3 -m venv venv && sudo -u nbabot venv/bin/pip install -r requirements.txt
sudo cp nba-news-bot.service /etc/systemd/system/
sudo systemctl enable --now nba-news-bot
journalctl -u nba-news-bot -f
```

Для проверки на своём компьютере: `pip install -r requirements.txt && python bot.py`.

## Как это работает

- При первом запуске бот запоминает уже опубликованные на сайтах новости и **ничего не постит** — дальше в канал идёт только новое. (Чтобы сразу опубликовать текущие — `POST_ON_FIRST_RUN=1`.)
- Состояние хранится в `data/seen.db`, перезапуск не создаёт дублей.
- Новости про two-way контракты, вызовы из фарм-клубов и права в G League помечаются `#GLeague`, остальное — `#NBA`.
- Если сайт временно недоступен, бот пишет предупреждение в лог и пробует снова через минуту.

## Ещё быстрее

Самые первые срочные новости (обмены, подписания) обычно появляются у инсайдеров в X (Twitter) — Шамс Чарания и другие — за минуты до статей на сайтах. Официальный API X платный, поэтому здесь он не подключён; его можно добавить отдельным источником, если появится доступ.
